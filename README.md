# Dice Roll Game

## About the Project

This is a simple Dice Roll Game developed using Python. The player competes against the computer by rolling virtual dice. The player with the higher number wins the round.

## Features

* Generate random dice numbers between 1 and 6.
* Play multiple rounds.
* Compare the player's result with the computer's result.
* Maintain scores for both players.
* Display the final score and overall winner.
* Use a menu to play again or exit.

## Technologies Used

* Python
* Random Module
* Functions
* Conditional Statements
* While Loop

## How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Run `main.py`.
4. Select the option to play the game.
5. Roll the dice and compete against the computer.

## Purpose

The project demonstrates the use of random numbers, loops, functions, and conditional statements in Python.
